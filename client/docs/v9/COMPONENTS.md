purpose line, and the same shared contract (depth / material / motion /
reducedMotionSafe / testID / accessibilityLabel / disabled, seven
states, seven platforms, one doNot list). The specification is that
contract, not 118 distinct designs — so names are mapped to real
implementations and the remainder is reported rather than filled with
stubs that render nothing.
