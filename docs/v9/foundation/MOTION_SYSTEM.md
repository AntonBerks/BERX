# Motion System

Motion has 4 jobs:
1. establish hierarchy;
2. explain spatial continuity;
3. confirm an action;
4. create emotional punctuation.

Never animate for decoration when it increases cognitive load.

### Transition choreography
1. Preserve shared element.
2. Move outgoing scene into lower depth.
3. Expand incoming shared object.
4. Rebuild surrounding environment.
5. Activate controls last.
6. Never block the user longer than the actual data operation.

### Reduced motion
Respect OS/browser reduced-motion settings. WCAG guidance includes reduced-motion techniques and mobile-specific application guidance. See W3C references in `09_QA/ACCESSIBILITY_REFERENCES.md`.
