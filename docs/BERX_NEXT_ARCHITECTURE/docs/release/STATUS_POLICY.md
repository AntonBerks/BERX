# BERX — STATUS POLICY

| Status | Meaning |
|---|---|
| PLANNED | designed and registered, no implementation claim |
| IMPLEMENTING | code exists but vertical slice is incomplete |
| STATIC_VERIFIED | syntax/types/static checks completed |
| RUNTIME_VERIFIED | real environment test completed |
| BLOCKED | cannot execute because required external/runtime infrastructure is absent |
| NOT_IMPLEMENTED | required code does not exist |

`PASS`, `READY` and `PRODUCTION` are release-level conclusions only after runtime gates pass.
