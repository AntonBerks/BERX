# BERX — DOMAIN MAP

| Domain | Core responsibility | Main dependencies |
|---|---|---|
| Identity/Auth | registration, login, recovery, sessions | OSSN core |
| Profile | identity presentation and editable profile | Identity, Media |
| Social Graph | follow/friend/block/circle relationships | Identity, Privacy |
| Feed | ranking and content presentation | Graph, Posts, Media, Privacy |
| Posts | create/edit/delete/share/save | Identity, Media, Privacy |
| Stories | ephemeral content | Identity, Media, Privacy |
| Reels/Video | short video | Posts, Media |
| Messaging | conversations, messages, attachments, reactions | Identity, Notifications, Media |
| Notifications | event-driven user alerts | all domains |
| Communities | community membership/content/moderation | Identity, Posts, Notifications |
| Places | locations, reviews, check-ins, saved places | Geo, Media |
| NOW | nearby live intent and business moments | Geo, Places, Business |
| Events | event lifecycle, RSVP, attendees | Places, Notifications |
| Match | discovery, like/pass/superlike, matches | Profile, Privacy |
| Discover/Search | global discovery | all indexed domains |
| Creator | creator profile and performance | Posts, Media, Analytics |
| Collections | saved/curated content | Posts, Places, Events |
| Experiences | structured real-world experiences | Places, Events |
| Trips | day-by-day travel plans | Places, Events, Experiences |
| Rewards | points, levels, achievements | verified actions |
| Business | business identity, team, media, offers | Places, Events, NOW |
| Commerce | offers/products/bookings/payment boundary | Business, Events |
| Settings | account, privacy, security, notifications | Identity, Privacy |
| Admin | moderation, reports, system controls | all domains |
| Media | image/video/audio lifecycle | storage + all content domains |
